# Enterprise Microsoft Entra ID | IAM & Identity Security

A hands-on portfolio focused on enterprise Identity and Access Management (IAM), Identity Governance (IGA), and Microsoft Entra ID security.

## Project Overview

This project explores the design, implementation, automation, and security of identity solutions in a simulated enterprise environment.

The goal is to demonstrate practical Microsoft Entra ID engineering skills through realistic business scenarios, technical implementations, and documented testing.

## Key Areas

- **Identity Lifecycle Management:** Joiner, Mover, and Leaver (JML)
- **Hybrid Identity:** Active Directory and Microsoft Entra ID
- **Identity Security:** Conditional Access, MFA, and Zero Trust
- **Privileged Access:** Privileged Identity Management (PIM)
- **Identity Governance:** Access Reviews and Entitlement Management
- **Application Integration:** SSO, SAML, OAuth 2.0, and OpenID Connect
- **Automation:** Microsoft Graph API and PowerShell
- **Monitoring & Security:** Identity auditing and incident response

## Project Approach

Each scenario will cover:

1. Business requirements
2. Solution architecture
3. Technical implementation
4. Security considerations
5. Testing and validation
6. Lessons learned
